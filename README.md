# Viagem Interview Task

Interactive web application for displaying cadastral parcels on a map.

## Stack

### Backend

- PHP 8.3
- Slim Framework
- SQLite

### Frontend

- React
- TypeScript
- Vite
- MapLibre GL

## Project structure

backend/
frontend/
data/

## Planned features

- Display cadastral parcels
- Load parcels by map bounding box
- Parcel detail popup
- Search by parcel number
